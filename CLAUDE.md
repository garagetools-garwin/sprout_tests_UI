# sprout_tests_UI — инструкции для Claude

UI-автотесты маркетплейса закупок Sprout (sprout-store.ru): Python + Playwright (sync) + pytest + Allure, CI в GitHub Actions.
Владелец — Артём, единственный разработчик в Garwin/Garagetools; разработку Sprout ведут подрядчики.

## С чего начать новую сессию

1. Прочитай `docs/claude/HANDOFF.md`: текущая задача, статус приёмки, дефекты, что делать дальше.
2. Исходные материалы приёмки (читать по необходимости):
   - `docs/claude/sprout-ui-checklist-2026-11-23.md` — чек-лист V1–V7 / A1–A10;
   - `docs/claude/sprout-ui-handoff-2026-11-26.md` — отчёт предыдущего прогона (GPT, 25.11).
3. Продолжай с раздела «Следующие шаги» в HANDOFF.md. Закончил шаг — обнови HANDOFF.md.

## Окружения

- Стейдж: `https://stage.sprout-store.ru` — основной стенд для приёмки. Использует prod-ID категорий (`PROD_DATA_HOSTS` в conftest).
- Прод: `https://sprout-store.ru` — только чтение, тестовые заказы на проде не создавать.
- Запуск: `pytest --url https://stage.sprout-store.ru -m claude` (опция `--url` из conftest; без неё берётся дефолт).
- Mailpit: `http://localhost:8025` — сюда приходят коды входа и письма со стейджа; API `/api/v1/messages`.
- GitLab с кодом Sprout: https://gitlab.garagetools.ru/sprout (front-end, back-end, pwa, sprout-infra). Локальные клоны: `C:\Users\user\Desktop\sprout-work\`.

## Соглашения кода

- Page Object Model в `page_opjects/` (опечатка в имени папки историческая — не переименовывать). Локаторы — константы класса, действия — методы с `@allure.step`.
- Страница создаётся через фикстуру `page_fixture()`: возвращает фабрику, трассировка и закрытие контекста уже внутри. Модалка выбора города снимается автоматически.
- Тест: `@allure.title(...)` на русском, шаги `with allure.step(...)`, assert с понятным сообщением на русском.
- **Каждый тест, написанный Claude:** `@allure.tag("AI", "claude", ...)` + `@pytest.mark.ai` + `@pytest.mark.claude` (маркеры зарегистрированы в `pytest.ini`).
- Тест, меняющий данные стенда, обязан вернуть их в `finally` (режим договора, временные лимиты, адреса и т. д.).
- Известный дефект — `@pytest.mark.xfail(strict=True, reason="Dn: ...")`, чтобы после исправления тест стал XPASS и xfail сняли.
- Предпочитай стабильные локаторы (`#id`, `[title=...]`, текст) классам вида `css-2nkxv5`: они меняются при пересборке фронта.
- Не ставь `time.sleep`, если можно дождаться видимости элемента или ответа сети.
